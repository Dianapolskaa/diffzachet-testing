Этот репозиторий содержит реализацию и модульное тестирование 25 вариантов заданий. Каждый вариант оформлен в виде отдельной ветки (`variantXX`), содержащей библиотечный модуль и набор модульных тестов.

## 📂 Структура проекта

Каждый вариант имеет унифицированную структуру:
├── CMakeLists.txt
├── README.md
├── lib/ # Библиотечный модуль (бизнес-логика)
│ ├── CMakeLists.txt
│ ├── include/file.h
│ └── src/file.cpp
└── tests/ # Тестовый субпроект
├── CMakeLists.txt
└── test_file.cpp

## 🛠 Сборка и запуск тестов

### Через Qt Creator:
1. Откройте корневой `CMakeLists.txt` в Qt Creator.
2. Нажмите **Собрать (Build)** (`Ctrl+B`).
3. Нажмите **Запустить тесты (Run)** (`Ctrl+R`). В консоли вы увидите `PASS` для всех тестов.

### Через командную строку:
```bash
mkdir build && cd build
cmake ..
make
ctest --output-on-failure
```
### Стратегия тестирования
При разработке тестов применялись следующие методики:
1. Классы эквивалентности — входные данные разделены на группы с одинаковым поведением (положительные, отрицательные, нулевые значения).
2. Анализ граничных значений — особое внимание границам (0, переполнение, високосные года, пустые строки/массивы).
3. Негативное тестирование — проверки на некорректные данные с ожиданием исключений (std::invalid_argument, std::runtime_error, std::out_of_range).
Параметризованное тестирование — QTest::addColumn и QTest::newRow для проверки множества сценариев в одном методе.

### Особенности реализации
Безопасность памяти: В вариантах со структурами данных (07, 08, 09) соблюдается Правило трёх (деструктор, конструктор копирования, оператор присваивания).
Обработка ошибок: Вместо магических чисел (-1) в критических ситуациях используются стандартные исключения C++.
Точность вычислений: При сравнении чисел с плавающей запятой используется эпсилон-сравнение (std::abs(a - b) < 1e-9).
